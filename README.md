# mlib

A machine learning and deep learning library built from scratch in C.

## Why

This project isn't meant to compete with or replace existing frameworks
like PyTorch or NumPy. The goal is to understand what's actually
happening underneath them — the mathematics, memory management,
numerical computing, and systems engineering that modern ML libraries
are built on. Every component here is implemented and understood from
first principles, not just wired together from existing libraries.

## Status

Early development. Core infrastructure (build system, project layout)
is being set up; no library functionality exists yet.
